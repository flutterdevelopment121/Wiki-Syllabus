# Wiki Syllabus

A beautifully designed, responsive Flutter application for navigating and tracking academic syllabi.  
Easily select your university, stream, semester, and subjects, and track your progress through each module.

---

## Features

- Modern frosted-glass UI with rounded cards and buttons
- Step-by-step navigation: Education Level → University → Stream → Semester → Subject → Modules
- Progress tracker for each subject (e.g., `2/3 done`)
- Mark modules as completed with a tick box
- Responsive design:  
  - On mobile, shows either modules or module content  
  - On desktop/tablet, shows both side by side
- Top-left back icon for intuitive navigation
- Theme color picker and dark mode toggle
- "Upload Today's Work" button for daily tracking

## Getting Started

1. **Clone the repository:**
   ```sh
   git clone https://github.com/flutterdevelopment121/Wiki-Syllabus.git
   cd Wiki-Syllabus
   ```

2. **Install dependencies:**
   ```sh
   flutter pub get
   ```

3. **Run the app:**
   ```sh
   flutter run
   ```
